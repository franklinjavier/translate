# Replace verification — 2026-10-21

## Evidence and correction

The user reported failure with both Return and the Replace button. Content-free logs from the installed app showed two `replacement unverified` outcomes. The source allowed an Accessibility write to report success without changing the document, then dismissed the popover without attempting a paste. This is a reproducible failure mode; the affected source application has not been identified yet.

Codex added a regression modeling an editor that accepts but ignores Accessibility writes. On the original implementation, the focused suite failed with three assertions: the result was unverified, the text stayed unchanged, and no paste occurred (`/tmp/translate-replace-red.log`). Claude implemented the correction; Codex independently reviewed and verified it.

Replacement now uses one native paste after validating the captured app, field and selection. Accessibility is used for reads and confirmation only. There are no Accessibility writes or mutation retries, so a delayed write cannot combine with a fallback paste to insert twice. Clipboard captures retain their re-copy check. A verified paste restores the previous clipboard only while it still owns its contents; unknown readback leaves the translation there. A readable document that remains unchanged produces an explicit error instead of a silent dismissal.

## Independent results

- `scripts/test.sh`: **218 tests in 34 suites passed**, log `/tmp/translate-replace-full.log`.
- Coverage includes one paste, duplicate phrases, UTF-16 selection after surrogate pairs, changed app/field/selection, cancellation, unreadable readback, ignored paste and coordinator error presentation without retry.
- Signed macOS build passed, log `/tmp/translate-replace-signed-build.log`.
- `git diff --check` passed.

## Limits

No source-app GUI was operated during this fix. The tests simulate editor and pasteboard behavior; successful replacement in the user's affected app is not yet verified. A read-only selection cannot accept a native paste. Existing CLI isolation and translation prompts are unchanged.
